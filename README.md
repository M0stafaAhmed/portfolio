## Run locally

```bash
python3 -m http.server 8000
```

Open [http://127.0.0.1:8000](http://127.0.0.1:8000).

The site is a static HTML/CSS/JavaScript application. Google Fonts are loaded from Google's CDN; the page content and scripts are local.

## Deploy with Firebase Hosting

The repository includes a root-level firebase.json.

```bash
firebase login
firebase deploy --only hosting --project YOUR_FIREBASE_PROJECT_ID
```

Replace the placeholder with the intended Firebase project ID. The Firebase CLI must be installed and authenticated.
