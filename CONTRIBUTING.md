# Contributing

This is a personal portfolio. Changes should preserve factual accuracy, accessibility, performance, and privacy.

## Content rules

- Do not invent employers, dates, qualifications, certifications, client relationships, or performance metrics.
- Use verified employment dates and accurate education details.
- Do not publish private contact information or confidential client details.
- Describe projects according to their actual implementation status; distinguish prototypes from deployed systems.

## Front-end rules

- Keep the site dependency-light.
- Preserve responsive behavior and keyboard access.
- Avoid arbitrary percentage ratings for skills.
- Escape dynamic content before inserting it into HTML.
- Document external assets and third-party resources.
